# 🧾 Windows 10 – Documenting Troubleshooting Steps (Simulated Helpdesk Case)

## 📌 Project Overview
This project demonstrates how to **document troubleshooting steps professionally** for a helpdesk scenario.  
It is a **simulated case study** created to showcase my ability to record clear, structured troubleshooting documentation — a key skill in IT support roles.  

The scenario focuses on resolving a **Blue Screen (BSOD)** issue after a driver update.

---

## 🎯 Objectives
- Practice a structured troubleshooting workflow (identify → test → resolve → verify).  
- Create professional-style ticket documentation.  
- Simulate communication and resolution logging for a support ticket.

---

## 🛠️ Tools & Skills Used
- Windows 10 Pro (Virtual Machine)
- Event Viewer / Device Manager
- Safe Mode & Driver Rollback
- Skills: Troubleshooting · Documentation · Communication

---

## 📋 Simulated Ticket Documentation

### 🧩 Issue
**Simulated user “Diego”** reported that his desktop computer shows frequent blue screen errors after a recent Windows update.  

**Error Message:**  
> `STOP 0x0000007E SYSTEM_THREAD_EXCEPTION_NOT_HANDLED`

---

### 🔍 Troubleshooting Steps

1. **Information Gathering**  
   - Collected error message from simulated user.  
   - Confirmed the issue occurred after a system update.  

2. **Safe Mode Testing**  
   - Booted into **Safe Mode** (F8).  
   - System ran without crashing.  

3. **Identified Root Cause**  
   - Checked **Device Manager → Display adapters**.  
   - Found a recently updated graphics driver.  

4. **Applied Fix**  
   - Rolled back the driver to the previous version.  
   - Restarted system normally.

5. **Verification**  
   - Observed stable operation for 30 minutes.  
   - No new critical errors in Event Viewer.

---

### ✅ Outcome
Rolling back the graphics driver resolved the BSOD issue.  
System stability restored in the simulated environment.

---

### 📌 Next Steps
- Disable automatic driver updates until a new stable version is available.  
- Document driver version for reference.
